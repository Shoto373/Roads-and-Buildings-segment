# Отчет об изменениях в кодовой базе
## Сегментация дорог и зданий на аэрофотоснимках (Roads & Buildings Segmentation)

---

## 1. Задачи доработки проекта

Перечень выполненных технических задач:
* **Сегментация дорог:** замена функции потерь на Combo Loss (Dice + BCE) для предотвращения разрывов тонких линий дорожного полотна.
* **Структура проекта:** объединение пяти отдельных скриптов в единую модульную систему с CLI.
* **Смешанная точность (AMP):** поддержка FP16 через PyTorch AMP для ускорения обучения на GPU и экономии видеопамяти.
* **Формат чекпоинтов:** переход с сериализации объектов Python (pickle) на словари весов (state_dict) с метаданными.
* **Контроль сходимости:** добавление Early Stopping и логирования в TensorBoard.
* **Совместимость с Windows:** устранение ошибок кодировки cp1251 и отключение предупреждений OpenCV о TIFF-файлах.

## 2. Изменения в кодовой базе (Было / Стало)

### 2.1. Структура скриптов

**Было:**
```text
train.py                 # Обучение только для зданий
train_road.py            # Копия train.py для дорог
trained_demo.py          # Инференс только для зданий
trained_demo_road.py     # Инференс только для дорог

```

**Стало:**
```text
config.py    # Единая конфигурация и CLI (--task road / building)
train.py     # Единое обучение: AMP, Combo Loss, Early Stopping
inference.py # Единый инференс: TTA, пакетная или одиночная обработка
evaluate.py  # Расчет метрик (IoU, Dice, Precision, Recall, Acc) в JSON
```

### 2.2. Функция потерь для дорог

**Было:**
```python
criterion = smp.losses.DiceLoss(mode='binary')
```

**Стало:**
```python
class ComboLoss(nn.Module):
    def __init__(self, dice_weight=1.0, bce_weight=1.0):
        super().__init__()
        self.dice = smp.losses.DiceLoss(mode='binary', from_logits=True)
        self.bce = nn.BCEWithLogitsLoss()
        self.dice_weight = dice_weight
        self.bce_weight = bce_weight

    def forward(self, pred, target):
        return self.dice_weight * self.dice(pred, target) + self.bce_weight * self.bce(pred, target)
```

### 2.3. Смешанная точность (AMP)

**Было:**
```python
outputs = model(images)
loss = criterion(outputs, masks)
loss.backward()
optimizer.step()
```

**Стало:**
```python
scaler = torch.amp.GradScaler('cuda', enabled=use_amp)
with torch.amp.autocast('cuda', enabled=use_amp):
    outputs = model(images)
    loss = criterion(outputs, masks)
scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()
```

### 2.4. Сохранение чекпоинтов

**Было:**
```python
torch.save(model, './best_road_model.pth')
```

**Стало:**
```python
checkpoint = {
    'epoch': epoch,
    'state_dict': model.state_dict(),
    'best_iou': best_iou_score,
    'model_config': {'encoder': cfg.model.encoder, 'decoder': cfg.model.decoder},
    'task': cfg.task
}
torch.save(checkpoint, save_path)
```

**Примечание:** Загрузчик весов в `inference.py` и `evaluate.py` поддерживает как новые state_dict, так и старые pickle-файлы.

### 2.5. Мониторинг и ранняя остановка

В `train.py` добавлены:
* **TensorBoard:** запись потерь и IoU (`runs/road`, `runs/building`).
* **Early Stopping:** остановка обучения при отсутствии роста валидационного IoU (`--patience`).
* **tqdm:** вывод текущего loss на каждом батче.

### 2.6. Test-Time Augmentation (TTA)

Усреднение предсказаний исходного кадра, горизонтального и вертикального отражений:
```bash
python inference.py --task road --tta --num-examples 8
```
