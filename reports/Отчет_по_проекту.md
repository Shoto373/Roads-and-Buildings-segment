# Отчет по проекту: Сегментация зданий и дорог на аэрофотоснимках

## 1. Описание решения
В рамках данного проекта реализовано решение для автоматического распознавания (сегментации) зданий и дорог на аэрофотоснимках высокого разрешения. В качестве архитектуры нейронной сети используется **UNet** с предобученным энкодером **EfficientNet-B7**, реализованная с помощью библиотеки `segmentation_models_pytorch`. Данное решение позволяет на вход получать спутниковый/аэроснимок, а на выходе формировать бинарную маску, точно выделяющую пиксели, принадлежащие зданиям или дорогам. 

## 2. Конфигурация системы для запуска
Обучение и инференс производились на следующей конфигурации:
* **Операционная система:** Windows
* **Центральный процессор (CPU):** AMD Ryzen 5 5600 6-Core Processor
* **Видеокарта (GPU):** NVIDIA GeForce RTX 5060 (8 ГБ видеопамяти, CUDA 13.3)
* **Версия Python:** 3.14.6
* **Ключевые библиотеки (согласно requirements.txt):**
  * `torch` и `torchvision` (с поддержкой CUDA)
  * `segmentation-models-pytorch` (архитектуры для сегментации)
  * `albumentations` (аугментация данных)
  * `opencv-python`, `numpy`, `matplotlib` (обработка изображений)

## 3. Подробная инструкция по запуску

> [!IMPORTANT]
> Для обучения моделей потребуются датасеты [Massachusetts Buildings Dataset](https://www.kaggle.com/datasets/balraj98/massachusetts-buildings-dataset) и [Massachusetts Roads Dataset](https://www.kaggle.com/datasets/balraj98/massachusetts-roads-dataset).

**Шаг 1. Клонирование репозитория**
```bash
git clone https://github.com/Shoto373/Roads-and-Buildings-segment.git
cd Roads-and-Buildings-segment
```

**Шаг 2. Создание и активация виртуального окружения**
```bash
python -m venv .venv
# Для Windows:
.\.venv\Scripts\activate
# Для Linux/Mac:
source .venv/bin/activate
```

**Шаг 3. Установка зависимостей**
```bash
pip install -r requirements.txt
```

**Шаг 4. Подготовка данных**
Убедитесь, что у вас настроен Kaggle API (`kaggle.json` в `~/.kaggle/`).
Скачайте датасеты и распакуйте их в папку `notebooks/input/`:
```bash
# Для зданий
kaggle datasets download -d balraj98/massachusetts-buildings-dataset
# Для дорог
kaggle datasets download -d balraj98/massachusetts-roads-dataset
```

**Шаг 5. Запуск обучения**
Для запуска обучения модели сегментации зданий выполните команду:
```bash
python train.py
```
Для обучения модели сегментации дорог:
```bash
python train_road.py
```
*Примечание: скрипты автоматически сохранят лучшие веса в папке `weights/`.*

**Шаг 6. Запуск инференса (демонстрации)**
Для генерации предсказаний на тестовых данных запустите один из демо-скриптов:
```bash
python trained_demo.py       # Демо для зданий
python trained_demo_road.py  # Демо для дорог
```
Результаты будут сохранены в папке `outputs/`.

## 4. Источник изображений (происхождение данных)
Изображения для примеров были взяты из публичных наборов данных **Massachusetts Buildings Dataset** и **Massachusetts Roads Dataset** (созданы Владимиром Мнихом). 

> [!NOTE]
> **Источник:** Данные представляют собой ортофотопланы (аэрофотосъемка, а не космический аппарат), покрывающие различные регионы штата Массачусетс (США).
> **Пространственное разрешение:** 1 метр на пиксель (1m/pixel).
> **Размер снимков:** 1500 × 1500 пикселей.
